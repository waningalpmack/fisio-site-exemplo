# FisioCare - Landing Page para Clínica de Fisioterapia

## 🏥 Sobre o Projeto

Landing page institucional desenvolvida para uma clínica de fisioterapia especializada em Ortopedia, Traumatologia e Reabilitação. O projeto foi criado com foco em conversão, transmitindo credibilidade e humanização no atendimento.

**Objetivo:** Apresentar os serviços, gerar leads qualificados através do formulário de contato e facilitar o agendamento via WhatsApp.

## 🎯 Público-alvo

Pessoas que buscam tratamento fisioterapêutico para:
- Lesões ortopédicas e traumáticas
- Reabilitação pós-cirúrgica
- Preparação e recuperação esportiva
- Fortalecimento muscular e condicionamento físico
- Alívio de dores crônicas e restrições de movimento

## 🧩 Estrutura e Experiência do Usuário

### Navegação
- Menu fixo no topo com links diretos para todas as seções
- Menu hambúrguer para dispositivos móveis
- Scroll suave entre as seções

### Seções
1. **Hero** - Impacto visual com chamada clara para ação (CTA)
2. **Stats** - Diferenciais do serviço em cards
3. **Serviços** - Cards com as 6 especialidades, cada um com CTA individual para WhatsApp
4. **Sobre** - Apresentação da empresa com qualificações e certificações
5. **Valores** - 6 princípios que norteiam o atendimento
6. **Experiência** - Áreas de atuação e formação acadêmica
7. **FAQ** - Perguntas frequentes com accordion
8. **Contato** - Informações e formulário de lead

## ⚡ Funcionalidades Interativas

- **Scroll Reveal:** Animações de entrada conforme o usuário rola a página
- **Accordion FAQ:** Expansão e retração de perguntas
- **Máscara de Telefone:** Formatação automática no campo (99) 99999-9999
- **Validação de Formulário:** Campos obrigatórios com feedback visual
- **Envio via EmailJS:** Disparo de e-mail sem necessidade de servidor
- **Botão Flutuante WhatsApp:** Acesso rápido ao contato
- **Botão Voltar ao Topo:** Navegação facilitada

## 📊 SEO e Performance

### Otimizações implementadas
- Meta tags descritivas (description, keywords, author)
- Open Graph para compartilhamento em redes sociais
- Twitter Cards
- Schema.org (JSON-LD) para rich snippets
- Canonical tag
- Favicon e ícones para dispositivos
- Lazy loading de imagens (implícito)

### Performance
- CSS e JS inline (sem requisições externas adicionais)
- Fontes carregadas com `preconnect`
- Design leve e otimizado

## 📧 Formulário de Contato

**Campos:**
- Nome completo (obrigatório)
- E-mail (obrigatório, validação de formato)
- Telefone/WhatsApp (obrigatório, validação de quantidade de dígitos)
- Serviço de interesse (select)
- Mensagem (obrigatória)

**Fluxo:**
1. Validação em tempo real
2. Envio assíncrono via EmailJS
3. Feedback visual de carregamento
4. Mensagem de sucesso ou erro
